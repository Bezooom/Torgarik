# Инструкция для людей (не для роботов)

Если прошлые тексты были «про шарпы и OOS» — забудь.  
Здесь только: **что нажать, в каком порядке, что смотреть, чего не делать.**

---

## 0. Одной фразой: что это за проект

**Торгарик** — это не «кнопка напечатать деньги».

| Роль | Кто |
|------|-----|
| **Думает и решает** | Ты (режим S1 — skill, руками) |
| **Следит, режет риск, пишет журнал** | Бот (risk shell) |
| **Где деньги (если когда-нибудь live)** | Биржа **Hyperliquid** |
| **Чего нет по умолчанию** | Авто-робота, который сам жжёт депозит «по стратегии из твиттера» |

Пока система **не зелёная** по проверкам — live-автоматика **заморожена**. Это нормально и **специально**.

## 1. Что тебе нужно один раз

1. Компьютер с Linux (у тебя уже есть).
2. Установленные `cargo` / Rust (если `cargo --version` ругается — поставь Rust).
3. Открыть терминал в папке проекта:
   ```bash
   cd Torgarik   # папка, куда ты склонировал репозиторий
   ```
4. (По желанию) `jq` для красивых статусов: `sudo apt install jq`

**Ключи кошелька и live сейчас не обязательны.**  
Можно жить неделями в режиме «смотрю и учусь», без реальных ордеров.

## 2. Ежедневный порядок (главный путь)

Делай **только это**, пока не освоишься. Не лезь в «чудо-ботов» из соцсетей.

### Шаг 1 — Запуск «всего нужного»

```bash
cd Torgarik   # папка, куда ты склонировал репозиторий
bash scripts/start.sh
```

Что произойдёт:

- поднимется **щит** (risk shell) — следит и пишет журнал;
- поднимется **панель** (dashboard) в браузере.

Открой: [http://127.0.0.1:8080](http://127.0.0.1:8080)

Остановить всё:

```bash
bash scripts/start.sh stop
```

Логи:

```bash
bash scripts/start.sh logs shell
bash scripts/start.sh status
```

### Шаг 2 — «Можно ли вообще live?»

```bash
bash scripts/ready.sh
```

Читай **последнюю строку**:

| Что пишет | Что делать тебе |
|-----------|-----------------|
| **FROZEN** / Not ready | **Ничего с live.** Работай руками (S1) или просто смотри. |
| Ready / green (редко) | Всё равно читай `docs/LIVE_UNLOCK.md` перед любыми ключами. |

Пока видишь красные OOS / holdout — **это не баг**, это предохранитель: «автомат не доказал край».

### Шаг 3 — Твоя работа руками (S1)

Бот **не заменяет** торговлю. Ты:

1. Смотришь рынок / свои правила.
2. Если решил сделку — **не** вводишь ключи в чат, а (когда освоишь shell) пишешь сигнал в файл  
   `runtime/signals.jsonl` — см. раздел 5.
3. Ведёшь свой учёт: `python3 scripts/s1_status.py` (если пользуешься S1-скриптами).

Подробнее про доход skill-путём: [S1_SHELL_INCOME.md](S1_SHELL_INCOME.md).

### Шаг 4 — В конце дня

```bash
bash scripts/start.sh stop   # если больше не нужно
```

Журнал за сегодня (если shell работал):

```bash
ls runtime/journal/
# пример:
# tail -n 20 runtime/journal/journal_$(date +%Y%m%d).jsonl
```

## 4. Словарь на пальцах (без понтов)

| Слово | Как думать |
|-------|------------|
| **Dry / paper** | Игра в шахматы без ставок. Бот делает вид, что торгует. |
| **Live** | Уже настоящие деньги. Пока **закрыто** предохранителем. |
| **OOS** | «Прогнали стратегию на данных, которые она не зубрила». Если там минус — live нельзя. |
| **Holdout** | Ещё более честный хвост данных. Тоже должен быть в плюсе. |
| **Kill-switch** | Авто-стоп: «условия плохие → live не пускаем». |
| **Risk shell** | Охранник: режет слишком большой размер, дневной минус, чужие монеты. |
| **Journal** | Чёрный ящик: что случилось, почему ордер/сигнал отвергли. |
| **S1** | Ты торгуешь skill’ом; бот помогает не слиться и всё записать. |
| **Kelly** | Формула «сколько % банкролла рискнуть». В демо — **подсказка**, не ордер. |

## 5. Как подать сигнал shell (когда дойдёшь)

Файл: `runtime/signals.jsonl`  
**Каждая строка — один JSON.** Старые строки при старте shell **не** переигрываются (берётся только новое с конца).

Примеры (ещё раз: live ордера только при особом запуске + ключи + зелёный OOS):

```json
{"coin":"ETH","side":"buy","size":0.05,"note":"мой лонг","source":"me"}
{"coin":"ETH","side":"flat","note":"закрыть"}
```

| side | смысл |
|------|--------|
| `buy` / `long` | лонг |
| `sell` / `short` | шорт |
| `flat` / `close` | закрыть |

Полнее: [RISK_SHELL.md](RISK_SHELL.md).

**Пока учишься — можно shell не кормить сигналами.** Просто держи `start.sh` и смотри dashboard.

## 6. Про посты «бот сделал миллион»

Почти всегда это либо подгонка правил под прошлое, либо реклама, либо гонка
скоростей, где частник опаздывает. Торгарик проверяет любую идею одинаково:
бэктест → OOS → holdout → предохранитель. Результаты наших проверок — в
[RESEARCH.md](RESEARCH.md).

## 7. Чего **не** делать (список «если сделаешь — сам виноват»)

1. **Не** вставляй приватный ключ в чат, в git, в скриншоты.  
2. **Не** ставь `CONFIRM_LIVE=1` и live-режим, пока `ready.sh` красный.  
3. **Не** верь постам «бот сделал миллион» — проверяй на истории и holdout.  
4. **Не** увеличивай размер «потому что уверен» — охранник как раз против этого.  
6. **Не** жди, что dashboard сам открывает сделки — он **смотрит**, не стреляет.

## 8. Если что-то сломалось

| Симптом | Что сделать |
|---------|-------------|
| `start.sh` падает на сборке | `cargo check -p ml-trader` — пришли ошибку; часто просто долго качает зависимости |
| Dashboard не открывается | `bash scripts/start.sh status`; порт занят → `bash scripts/start.sh stop` и снова |
| `ready.sh` орёт про jq | `sudo apt install jq` или читай fallback |
| Нет `wf_latest.json` | Отчёт backtest не сгенерен — live и так нельзя; для учёбы не критично |
| Страшно / ничего не понятно | Оставь только `start.sh` + браузер + эту страницу. Остальное — потом |

Ещё: [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 11. Мини-FAQ

**Q: Где кнопка «заработать как в твиттере»?**  
A: Нет такой. И не будет, пока research + OOS не докажут край. Сейчас money-path = **ты + дисциплина + щит**.

**Q: Бот торгует сам?**  
A: В режиме shell по умолчанию — **нет** (dry / мониторинг). Авто-alpha live — **заморожена**.

**Q: Я вообще не программист. Мне сюда?**  
A: Да: две команды — `start.sh` и `ready.sh`. Остальное — по желанию.

**Q: На каком языке просить помощь у агента?**  
A: Как удобно. Но опирайся на **эту** инструкцию: «сделай как в §2» / «упал start.sh».
