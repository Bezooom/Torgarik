# Non-bot money paths (РФ) — без магии

Не алго-«печатный станок». Реалистичные направления, если OOS alpha красный  
(сейчас так: см. [LIVE_UNLOCK.md](LIVE_UNLOCK.md), [S1_SHELL_INCOME.md](S1_SHELL_INCOME.md)).

## 1. Доход «по часам / навыку» (самый предсказуемый EV)

| Путь | Плюсы | Минусы |
|------|--------|--------|
| Фриланс / remote (dev, data, support) | Деньги за работу, не за удачу | Нужен skill pipeline |
| B2B мелкий сервис | Повторяемый cashflow | Продажи |
| Контент / обучение **после** track record | Масштаб | Долго, без аудитории = 0 |

**EV выше**, чем у бота с OOS ≤ 0.

## 2. Крипта / рынки **без** direction bot

| Путь | Реализм для РФ |
|------|----------------|
| P2P спред (осторожно, комплаенс/скам) | Высокий operational risk |
| OTC / обмен в доверенном круге | Trust-limited |
| Стейкинг / yield **только** понятный протокол, малый % капитала | Не «x10» |
| Арбитраж руками CEX–P2P (если доступы есть) | Трудоёмко, capacity мал |

Правило: **не** класть в yield/P2P деньги, которые нельзя потерять на контрагенте.

## 3. Трейдинг как **skill**, не как ATM

- Размер: «учебный»  
- Journal (наш shell) обязателен  
- Нет OOS → нет live size  
- Цель: **навык + дисциплина**, не «закрыть ипотеку ботом»

## 4. Продукт вокруг бота (meta)

Вместо «бот зарабатывает»:

- Risk journal SaaS / open-source reputation  
- Алерты anomaly → Telegram (свой use-case)  
- Консалт «как не слить» для друзей  

Деньги от **людей**, которым нужен процесс.

## 5. Чего избегать

- VPN + рынки ставок «гарантированный edge»  
- Сигнал-каналы с ROI в рекламе  
- Плечо на HL alts «потому что funding красивый»  
- Все spare money в один bot  

## Практичный 30-дневный план (смешанный)

| Неделя | Фокус |
|--------|--------|
| 1 | Shell + journal каждый день; 0 auto trades |
| 1–2 | Anomaly logger + `analyze_hypotheses.py` — есть ли H1/H2 |
| 2–4 | **Параллельно** income skill (фриланс/оффер) ≥ N часов/нед |
| 4 | Решение: trading остаётся hobby с hard loss cap **или** пауза |

**Критерий:** через 30 дней доход вне бота > 0 **или** явный skill progress; bot не «должен» кормить.

## Связь с этим репо

| Режим | Роль |
|-------|------|
| `--mode shell` | риск + журнал + **твой** сигнал |
| `--mode anomaly` | охота за структурой |
| `--mode alpha` | research only, пока OOS красный |
| Backtester | truth serum |

Итог: **машина для денег в РФ сейчас — это ты + навык + дисциплина**, а репо — **щит и микроскоп**, не печатный станок.
