Live vs dry-run (учебный режим)

Dry-run / paper — бот смотрит цены и ведёт журнал, но не тратит реальные деньги. Live — реальные ордера. По умолчанию всё в dry-run.

Risk shell (щит)

Программа-сторож: лимиты, дневной стоп-убыток, журнал, проверка сигналов. Работает командой cargo run -p ml-trader -- --mode shell.

OOS / holdout / kill-switch

OOS — проверка стратегии на «невидимых» данных. Holdout — самый честный хвост истории. Kill-switch — авто-блокировка live, если цифры красные или NaN.

S1 (skill path)

Главный путь заработка: ваши часы практики + дисциплина. Бот — щит и микроскоп, а не «банкомат».

Почему дашборд не торгует?

Это read-only интерфейс. Он только читает journal и отчёты. Ордера возможны только из shell/live CLI после жёстких проверок.

Как читать этот экран за 30 секунд

Это не торговый терминал. Это «приборная панель безопасности».

  • Большой блок сверху — можно ли live-автоторговлю. Если НЕТ — деньги автоматом не уйдут.
  • Четыре плитки — капитал, ваши часы практики, качество стратегии, прибыль на тесте.
  • Что сделать сейчас — конкретные шаги и команды (можно скопировать).
  • Словарь — если термин незнаком, раскройте строку.

Подсказки можно снова открыть кнопкой «Как это читать».
