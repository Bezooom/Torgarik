# Как помочь проекту

Спасибо за интерес! Торгарик — исследовательский проект. Главная ценность здесь —
**честность проверок**, а не «прибыльность».

## Быстро

```bash
git clone https://github.com/Bezooom/Torgarik.git && cd Torgarik
cargo build --workspace
cargo test --workspace
```

Нужен Rust ≥ 1.88 и `pkg-config` + `libssl-dev`.

## Правила

1. **Не ослабляйте предохранитель.** PR, который включает живую торговлю,
   снижает пороги `OosStats` или обходит `CONFIRM_LIVE`, будет отклонён.
   Порядок разморозки описан в [docs/LIVE_UNLOCK.md](docs/LIVE_UNLOCK.md).
2. **Новая стратегия = предрегистрация.** Сначала опишите правила и зафиксируйте хеш
   (`backtester --prereg-only`), потом запускайте. Прикладывайте отчёт walk-forward
   **с holdout**. Подробно: [docs/PREREG.md](docs/PREREG.md), [docs/BACKTEST.md](docs/BACKTEST.md).
3. **Никаких секретов** в коде, конфигах, тестах и отчётах. Только переменные окружения.
4. **Нет `.unwrap()` / `.expect()`** на `Option`/`Result` в рабочем коде (в тестах можно).
5. Новое поведение — с тестом. `cargo test --workspace` должен проходить.
6. Форматирование: новый и изменённый код — через `cargo fmt`. Весь проект пока
   не отформатирован; массовое переформатирование — отдельным PR, без изменений логики.
7. Новые площадки — только с отдельным обсуждением в issue; клиенты рынков предсказаний
   (Polymarket и т.п.) удалены намеренно и обратно не добавляются.

## Коммиты и PR

- Короткое понятное название: `backtester: add embargo to holdout split`.
- Описание: что изменилось, зачем, как проверено.
- Изменения в поведении — строка в [CHANGELOG.md](CHANGELOG.md) в разделе `Unreleased`.

## Язык

Документация в основном на русском; issues и PR можно писать на русском или английском.

## Лицензия вклада

Отправляя вклад, вы соглашаетесь, что он распространяется на условиях
MIT OR Apache-2.0, как и весь проект.
